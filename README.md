#### 🛰️ Proyecto destacado

**[CIBERNAV](https://github.com/rikianeiros/cibernav)** — Suite de auditoría de seguridad de redes.
Reconocimiento Wi-Fi, ataques de auditoría (handshake/PMKID + crackeo), escaneo de puertos con
detección de CVEs, reconocimiento web (OSINT + fase activa) y un **modo naval** que demuestra
la exposición de los datos de navegación (NMEA). Con salida por **Tor**, modo pasivo e informes en PDF.

`Python` · `FastAPI` · `nmap` · `aircrack-ng` · `Kali Linux`
